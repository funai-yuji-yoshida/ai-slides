API

APIとは：ソフトどうしの「窓口」

API（Application Programming Interface）は、あるソフトが、別のソフトの機能やデータを使うための「決まった窓口」です。レストランにたとえると、注文を受ける窓口にあたります。

お客さん

あなたのアプリ

「顧客の一覧がほしい」と、決められた書き方で頼む。

窓口

API

頼み方（書き方）のルールを決めている。ルールどおりでなければ、受け付けない。

厨房

サービス本体

データや機能を持っている。窓口を通してだけ、やりとりする。

中身（厨房）を知らなくても、窓口のルールを守れば使える。

いまの業務で使われるAPIは、インターネット経由でやりとりする「Web API」が中心です。

エンドポイント

エンドポイント：窓口の「住所」と「頼み方」

エンドポイントは、APIの窓口の住所（URL）です。「どの住所に（URL）」「どう頼むか（メソッド）」の組み合わせで、できることが決まります。選んで確かめましょう。

MCP

MCPとは：AI向けの「共通コネクタ」

MCP（Model Context Protocol）は、AIアプリと、外部のツールやデータをつなぐための共通の決まりです。Anthropic社が2024年に公開した、オープンな規格です。

MCPがないと

つなぎたいサービスごとに、AIアプリ側で、個別のつなぎ込みを作る必要がある。

MCPがあると

サービス側が「MCPサーバー」を用意すれば、MCPに対応したAIアプリから、同じ作法でつなげる。

① クライアント

AIアプリ側

Claude などの、MCPに対応したアプリ。

② サーバー

ツールを提供する側

「使える道具の一覧」と「使い方」をAIに教える。

③ 道具

ツール・データ

検索、ファイル読み取り、予定の登録など。

AIにとっての、USB-Cのような共通の差し込み口。

違い

APIとMCPの違い

MCPは、APIを置き換えるものではありません。多くの場合、MCPサーバーの裏側で、APIが呼ばれています。観点を選んで、比べましょう。

認証

認証と認可：「誰か」と「何ができるか」

APIは、誰でも自由に使えるわけではありません。「誰からの依頼か」を確かめ（認証）、「何をしてよいか」を決めます（認可）。代表的な方式を比べましょう。

セキュリティ 1

APIキーを、どこに置く？

APIキーは、持っている人が、その権限で使えてしまう「合い鍵」です。置き場所を選んで、安全かどうか確かめましょう。（キーは架空の例です）

api_key = "demo-key-3f9a1c7e…"
セキュリティ 2

MCPならではのリスク

MCPは、AIが自分で道具を選んで使うため、APIとは違う注意点があります。選んで、対策を確認しましょう。
