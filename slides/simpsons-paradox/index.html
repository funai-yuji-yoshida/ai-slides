シンプソンのパラドックス

全体で見ると、結論が逆になる

グループ別に見ると、どちらもAが勝っている。なのに、全部まとめるとBが勝つ。そんな不思議なことが、実際のデータでは起こることがあります。架空のキャンペーンデータで体験し、AIに集計を頼むときの注意点まで考えます。

本ページの事例・数値は、説明のための架空の例です。

船井総合研究所 AIソリューション開発室

体験 1

どちらのキャンペーンが、効果的？

架空の会社が、2つの営業キャンペーン（A・B）を、それぞれ350件のお客様に実施しました。成約した割合（成約率）を比べます。切り替えて、見え方の違いを確かめてください。

架空のデータです。「成約」は、契約に至った件数を表します。

仕組み

なぜ逆転するのか：件数の偏り

Aは、どちらのお客様でもBより成約率が高いのに、全体ではBに負けました。理由は、Aが担当したお客様の中身にあります。

既存のお客様新規のお客様全体
A81 / 87件（93%）192 / 263件（73%）273 / 350件（78%）
B234 / 270件（87%）55 / 80件（69%）289 / 350件（83%）

ポイント

新規のお客様は、もともと成約しにくい。Aは、その新規のお客様を263件（75%）も担当していました。Bは80件（23%）だけです。

「成約しにくいお客様」を多く引き受けた分、Aの全体の成約率は下がって見えます。

動かして確かめる

各お客様タイプの成約率は、そのまま（A：既存93%・新規73%）。Aが担当する「新規」の割合だけを動かします。Bは、新規が23%のままです。

考え方

原因は「隠れた条件」

この例では、「お客様のタイプ」が、キャンペーンの割り当てと、成約率の両方に影響しています。このような条件を「交絡（こうらく）因子」と呼びます。

① 割り当てに影響

お客様のタイプ

Aは新規が多く、Bは既存が多い。どちらを使うかが、お客様のタイプと結びついている。

② 結果に影響

成約のしやすさ

新規のお客様は、もともと成約しにくい傾向がある。キャンペーンの効果とは別の理由。

③ すると…

全体の比較がゆがむ

キャンペーンの良し悪しと、お客様の違いが混ざる。全体の平均だけでは、見分けられない。

平均や合計は、中身の違いをならして隠すことがある。

他にも、大学の入試データなどで、同じ形の現象が報告されています（例：1973年のカリフォルニア大学バークレー校の大学院入試の分析）。

判断

では、全体と別々、どちらを信じる？

「いつも別々に見るのが正しい」とは限りません。データが、どのようにできたかで変わります。状況を選んで、考え方を確認しましょう。

AI活用

AIに集計を頼むときの注意

AIは、頼まれた集計を、そのとおりに出してくれます。ただし、「どう切り分けるか」までは、頼まなければ考えないことがあります。

AIへの頼み方

返ってきそうな答え

  • ✓
    切り口ごとの集計も出してもらうお客様タイプ・地域・時期・担当者など、結果に影響しそうな項目で。
  • ✓
    件数も一緒に出してもらう割合だけでなく、母数（件数）を見ると、偏りに気づける。
  • ✓
    全体と別々で結論が違ったら、立ち止まるデータのでき方（誰が、どちらを選んだか）を確認する。
