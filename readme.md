# AI知識スライド集

「AIを使う人」から「AIにデータを食わせて仕事をさせる人」へ。

生成AIを業務で活用するために必要な基礎知識を、ブラウザで操作できるインタラクティブなHTMLスライドでまとめたものです。専門用語を身近なたとえと具体例で説明し、実際にクリックして動きを確かめながら理解できるように作っています。

## スライドを見る

**https://funai-yuji-yoshida.github.io/ai-slides/**

一覧ページから各スライドを開けます。インストールやログインは不要で、PC・スマートフォンのブラウザで閲覧できます。

## スライドの操作

| 操作 | 方法 |
|---|---|
| ページ送り | ← → キー、画面下のボタン、スワイプ |
| 目次 | 画面左下の「目次」ボタン |
| 一覧へ戻る | 画面左下の「一覧」ボタン |

スライド内のボタンや表をクリックすると、表示が切り替わったりデータがつながったりします。

## 対象

- 生成AIを使い始めたが、回答の質を上げる方法がわからない方
- 業務データをAIに渡して仕事をさせたい方
- 社内研修や勉強会の教材を探している方
